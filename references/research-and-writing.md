# 检索、论证与写作方法

仅在任务涉及选题、文献、提纲或正文时读取本文件。

## 1. 从课程名到研究问题

先生成大方向，再用至少一个“材料边界”和一个“分析边界”收窄：

- 材料边界：特定文本、案例、政策、作品、群体、事件或数据；
- 分析边界：时间、地点、理论视角、生产/传播环节、制度机制或争议点。

一个合格问题应满足：

- 不是仅靠定义即可回答；
- 可以在规定篇幅内完成；
- 有可取得的可靠材料；
- 答案能形成一个中心判断，而不是材料罗列。

不要把“与专业结合”或“追热点”当作硬性要求。只有它们能改善材料可得性或分析质量时才采用。

## 2. 检索式设计

为主题建立小型词表：

| 类别 | 内容 |
|---|---|
| 核心概念 | 题目中的主要对象与理论词 |
| 同义词 | 不同学科或年代的相近叫法 |
| 上位概念 | 扩大结果范围的领域词 |
| 下位概念 | 更具体的机制、类型或案例词 |
| 限定词 | 时间、地点、对象、材料来源 |

先用“核心概念 + 机制/问题”检索；结果过多时增加限定词，结果过少时替换同义词或回到上位概念。浏览高相关结果的关键词，补充领域真实用语。

优先使用学校图书馆、学术数据库、出版社、期刊官网、政府或机构官网。搜索引擎可用于定位，不能替代来源核验。

## 3. 锚点文献与引用链

先筛 3–5 篇与研究问题高度相关的锚点文献，检查：

- 研究对象是否与题目一致；
- 论证是否直接涉及研究问题；
- 来源是否可靠、信息是否完整；
- 是否能获得摘要、全文或足够的原始信息；
- 是否代表关键理论、主要争议或重要材料。

再看其参考文献、被引文献和相近关键词。引用链只用于发现来源；引用之前仍需打开原文核对。

## 4. 证据矩阵

写作前维护最小证据表：

| 分论点 | 来源 | 证据或原意 | 定位 | 证据层级 | 使用方式 |
|---|---|---|---|---|---|
|  |  |  | 页码/章节/段落 | 全文/摘要/二手/待核 | 引用/转述/背景 |

规则：

- 直接引语必须来自已核对全文，并保留原文与定位；
- 摘要只能支持摘要明确陈述的内容；
- 二手引文应尽量追到原始来源，无法追溯时明确写“转引自”；
- 引文不能替代分析。引用后回答“这条证据如何支持本段判断”。

## 5. 论证提纲

先写中心论点，再拆为 2–4 个分论点。每个小节至少回答四件事：

1. 本节问题是什么；
2. 本节给出的判断是什么；
3. 哪些材料能支持判断；
4. 本节如何推进全文中心论点。

“概念—现状—成因—路径”只适合问题分析型论文。文本分析、历史梳理、理论讨论或案例研究应改用与材料相符的结构。

## 6. 正文生成与自然化修改

每个自然段围绕一个主要判断。可采用：

> 主题句 → 证据或具体材料 → 分析解释 → 与小节论点的连接

修改顺序：

1. 删除无法核验、偏离题目或重复的内容；
2. 补足从证据到结论之间的推理；
3. 合并机械重复的段落和标题；
4. 把空泛评价换成具体对象、动作和条件；
5. 统一术语、时态、引号和标点；
6. 保留用户自然表达，但不故意制造错别字或事实错误。

避免常见问题：万能开场、过度宣传性形容、无来源的“有研究表明”、连续三段式口号、意义不明的比喻、滥用冒号/破折号/引号，以及结语突然提出新材料。
